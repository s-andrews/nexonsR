An R package to analyse nanopore RNA-Seq quantitated with nexons

This R package can read in the output generated by the [nexons](https://github.com/s-andrews/nexons/) program, which quantitates long read (nanopore) RNA-Seq data at both a gene and isoform level.

It provides easy methods to perform exploration and quality control of the data as well as differential expression with [DESeq2]([nexons](https://github.com/s-andrews/nexons/)) or differential splicing analysis with [DRIMSeq](https://bioconductor.org/packages/release/bioc/html/DRIMSeq.html)

## Installation

You can install with any standard remote installation R package

* [pak](https://pak.r-lib.org/)
* [remotes](https://cran.r-project.org/web/packages/remotes/index.html)
* [devtools](https://cran.r-project.org/web/packages/devtools/index.html)
* [renv](https://rstudio.github.io/renv/articles/renv.html)

nexonsR uses packages from bioconductor so you may need to set this up in some of these frameworks.

### Using pak
```
install.packages("pak")
pak::pkg_install("s-andrews/nexonsR")
```

### Using renv
```
install.packages("renv")
renv::init(bioconductor=TRUE)
# Restart your R session to load renv
install.packages("s-andrews/nexonsR")
```


## Quick Usage Summary

### Loading and accessing Data
```r
library(nexonsR)

# Read in nexons output results
read_nexons("path/to/results", prefix = "nexons_output_") -> results

# See what was loaded
results

# Look at one of the quantitation tables
results$get_data("gene") 
results$get_data("partial")
results$get_data("gene", samples = c("sample-2", "sample-1"))
results$get_data("unique", units = "log2RPM")
```

### Adding metadata

Metadata is stored in a simple data frame with a column of samples which match the name of the quantitated files.

```r
# Get the existing metadata
results$get_metadata() -> metadata 

# Directly add an existing new metdata column
metadata$condition <- rep("control", nrow(metadata))

# Change the metadata data frame and add it back
metadata |>
  add_column(condition=rep(c("control","treated"), each=4)) |>
  add_column(sex=c("M","F","F","M","M","F","F","M")) -> metadata

results$set_metadata(metadata)
```

### Gene and Transcript metadata
You can access the gene names from the nexons files to annotate downstream results.  Gene and Transcript IDs are generally used for analysis

```r
results$gene_metadata()
results$transcript_metadata()
```

### QC - Coverage
You can get a quick summary of the number of observed genes or isoforms per sample.  You can set a threshold to say how many counts you want to see to count something as being observed.

```r
results$coverage()
results$coverage(file = "partial", threshold = 10)
results$coverage(file = "unique", level = "isoform")
```

### QC - Assignments
Reads can be assigned at a gene level, a partial match to an isoform or a full unique isoform match.  You can extract the metrics for these assigments to compare them per gene/isoform.

```r
# Get assignments at gene level across all files and samples
results$compare_assignments()

# Compare partial vs unique isoform assignments for one sample
results$compare_assignments(
    level = "isoform", 
    samples = "sample-1",
    units = "log2RPM"
)
```


### Differential Expression with DESeq2
After setting up your metadata you can run a DESeq2 model building directly.

```r
# Run DESeq2 on gene assignment counts
results$run_deseq2(~ condition) -> model
DESeq2::results(model)


# Run DESeq2 on gene level summed counts for isoform level assigned reads
results$run_deseq2(
    ~ condition, 
    file = "partial", 
    level = "gene"
) -> model

# Run DESeq2 at the isoform level using just a subset of samples.
results$run_deseq2(
    ~ condition, 
    file = "unique", 
    level = "isoform",
    samples = c("control1", "control2", "treated1", "treated2")
) -> model
                           )
```


### Differential Isoform Use with DRIMSeq

DRIMSeq identifies genes where the proportion of reads assigned to different isoforms differs between conditions.

```r
# DRIMSeq has a random component so for reproducibility set a seed.
set.seed(123)

# Fit the model
results$run_drimseq(~ condition) -> fit

# Look at the coefficient names
DRIMSeq::coefficients(fit) |> colnames()

# Get stats results for the tested coefficient
DRIMSeq::dmTest(fit, coef = "conditiontreated") -> tested

# Get the stats table for gene level metrics
DRIMSeq::results(tested)

# Get the stats table for isoform level metrics
DRIMSeq::results(tested, level = "feature") # Individual isoforms
```
